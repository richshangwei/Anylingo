## 一、產品簡介

**隨譯 Anylingo** 是一款 Windows 桌面翻譯工具，核心特色是「翻譯不綁在瀏覽器裡，在整台電腦通用」。

| 項目 | 說明 |
|---|---|
| 中文名 | 隨譯 |
| 英文名 | Anylingo |
| 版本 | 0.1.0 |
| 平台 | Windows 10 / 11 |
| 架構 | Tauri 2 + Rust + Svelte 5 |

**核心能力：**

- 選得到的文字 → 直接讀取翻譯
- 選不到的文字 → 框選截圖，OCR 辨識後翻譯
- 支援 8 種 AI 翻譯供應商（雲端 + 本機）
- 翻譯結果串流顯示，逐字出現
- 內建「解釋」功能，補充術語與語氣說明
- 完全本機 OCR，截圖不落地、不上傳
- API Key 加密儲存於 Windows 認證管理員
- 無遙測、無內容記錄

## 三、安裝與解除安裝

### 安裝

1. 取得安裝檔（`.exe` NSIS 安裝包）
2. 雙擊執行安裝檔
3. 依照安裝精靈完成安裝
4. 安裝完成後，程式會自動啟動並出現在系統匣

### 解除安裝

- 透過 Windows「設定 → 應用程式 → 已安裝的應用程式」找到「隨譯」並解除安裝
- 或執行安裝目錄中的解除安裝程式

> **注意**：解除安裝不會清除 `%APPDATA%/app.floatrans.desktop/` 中的設定資料。如需完全清除，請手動刪除該資料夾。

## 四、第一次啟動

首次啟動時，隨譯會：

1. **自動建立預設模型設定檔** — 「本機 Ollama」，端點 `http://127.0.0.1:11434`，模型 `qwen3:8b`
2. **註冊全域快捷鍵** — `Ctrl+Alt+T`（翻譯選取文字）與 `Ctrl+Alt+R`（截圖翻譯）
3. **顯示系統匣圖示**

### 開始使用前的準備

- **使用本機 Ollama**：請先安裝 [Ollama](https://ollama.com) 並執行 `ollama pull qwen3:8b` 下載模型
- **使用雲端供應商**：請準備好對應的 API Key（見[供應商設定指南](#十六供應商設定指南)）

## 五、三種翻譯方式

### 方式一：選取動作鈕（「譯」按鈕）

在任何應用程式中反白選取文字後，滑鼠旁會自動出現一個紅色「譯」按鈕。

1. 在任意應用程式中用滑鼠反白選取文字
2. 滑鼠旁出現出現紅色「譯」按鈕
3. 點擊「譯」按鈕
4. 翻譯面板以**簡易模式**出現在游標旁，顯示譯文

**適用場景**：瀏覽器、Word、記事本、PDF 閱讀器等支援 UI Automation 的應用程式。

**限制**：

- 密碼欄位一律排除，不顯示按鈕
- 部分自繪控制項（Scintilla / Notepad++、部分終端機、Java/Electron 介面）不暴露選取內容，不會出現按鈕 — 請改用快捷鍵 `Ctrl+Alt+T`

---

### 方式二：快捷翻譯 `Ctrl+Alt+T`

1. 在任意應用程式中反白選取文字
2. 按下 `Ctrl+Alt+T`
3. 翻譯面板以**簡易模式**出現，顯示譯文

**取字方式**：UI Automation 優先，失敗時自動切換到剪貼簿備援。

**剪貼簿備援規則**：

- 模擬 `Ctrl+C` 複製選取文字，翻譯後將剪貼簿還原為原始內容
- 只有剪貼簿為空或只含純文字時才執行
- 若剪貼簿含圖片、檔案、RTF、HTML 等無法無損還原的內容，會**拒絕執行**以保護您的剪貼簿內容
- 等修飾鍵放開後才送出 `Ctrl+C`（避免送出 `Ctrl+Alt+C`）

---

### 方式三：截圖翻譯 `Ctrl+Alt+R`

無法選取文字時，用截圖框選方式取得文字。

**三種啟動方式**：

| 入口 | 操作 |
|---|---|
| 全域快捷鍵 | `Ctrl+Alt+R` |
| 面板按鈕 | 點擊面板右上角「▣」按鈕 |
| 系統匣選單 | 右鍵系統匣圖示 → 「截圖翻譯」 |

**操作流程**：

1. 啟動後，畫面會壓暗（半透明遮罩）
2. 用滑鼠拖曳框選要翻譯的區域
3. 放開滑鼠 → 自動截圖 → Windows OCR 辨識 → 送出翻譯
4. 翻譯面板以**完整面板**模式顯示結果

**取消方式**：

- 按 `Esc` 取消
- 按右鍵取消

**注意事項**：

- 框選前，隨譯自己的視窗會先收起，避免遮住內容
- 框選區域太小（< 8px）視為誤觸，直接退出
- OCR 使用 Windows 內建引擎，完全在本機執行
- 截圖只留在記憶體，不落地、不上傳
- 只有辨識出的**文字**會送至模型端點
- 小範圍會自動放大（最多 4 倍）以提升辨識準確度
- 中日韓文字之間的斷詞空白會自動接回

**OCR 語言**：

- 自動取自系統慣用語言清單
- 備援順序：zh-Hant → zh-Hans → en → ja
- 若無可用語言套件，會提示您到 Windows 設定安裝

## 六、翻譯面板詳解

### 面板尺寸

| 狀態 | 尺寸（邏輯像素） |
|---|---|
| 完整面板 | 480 × 640 |
| 收合 | 48 × 48（只剩一顆圖示） |
| 簡易模式 | 380 × 220 |

### 視窗特性

- 恆常置頂（永遠在最上層）
- 無邊框
- 不可最大化
- 不顯示在工作列
- 關閉時隱藏而非結束程式（程式仍在系統匣中執行）
- 可拖曳（標題列區域）

### 三種面板模式

#### 完整面板

```
┌─────────────────────────────────────┐
│ 譯  隨譯 Anylingo    ▣  ⚙  ◇  —  × │  ← 標題列
├─────────────────────────────────────┤
│ [模型下拉 ▼]      [目標語言下拉 ▼]  │  ← 設定列
├─────────────────────────────────────┤
│  ▼ 原文                             │
│  ─────────────────────              │
│  譯文（串流顯示）●                   │  ← 內容區
│  ─────────────────────              │
│  解釋區（按需顯示）                  │
├─────────────────────────────────────┤
│ ● 待命  ◇  [停止] [解釋] [複製]     │  ← 底欄
└─────────────────────────────────────┘
```

#### 簡易模式（Mini Mode）

- 由「譯」按鈕與 `Ctrl+Alt+T` 觸發
- 只顯示譯文與複製按鈕
- 點「↗」可展開為完整面板

#### 收合狀態

- 縮小為右下角的一顆「譯」圖示（48 × 48），不顯示名稱
- **點圖示上任何位置**都能展開；按住拖曳則可搬動位置
- 收到新譯文時**自動展開**
- 展開後留在原地，不彈回右下角

### 標題列按鈕（由左至右）

| 按鈕 | 圖示 | 功能 |
|---|---|---|
| 回到首頁 | ⌂ | 清空這一輪的原文與譯文，還原視窗為完整面板 |
| 截圖翻譯 | ▣ | 啟動框選截圖 |
| 模型設定 | ⚙ | 開啟模型設定對話框 |
| 釘選位置 | ◇ / ◆ | 切換釘選狀態（◇ = 未釘選，◆ = 已釘選） |
| 收合 / 展開 | — / □ | 收合至右下角或展開 |
| 關閉 | × | 隱藏面板（不結束程式） |

### 內容區

- **原文展開 / 收合按鈕**：切換是否顯示原文
- **譯文區**：串流顯示，附狀態指示燈
  - 灰色 = 待命
  - 紅色脈動 = 串流中
- **解釋區**（按需顯示）：金色左邊框，含停止 / 收起按鈕

### 底欄

| 元素 | 說明 |
|---|---|
| 狀態指示 | 狀態燈 + 文字（翻譯中 / 已停止 / 待命）+ 釘選標記 |
| 停止按鈕 | 串流中顯示，點擊中斷翻譯 |
| 解釋按鈕 | 請模型補充說明術語、縮寫與語氣 |
| 複製譯文按鈕 | 複製至剪貼簿，顯示「已複製」1.4 秒 |

### 右鍵選單（面板上右鍵）

| 項目 | 快捷鍵 |
|---|---|
| 回到首頁 | — |
| 截圖翻譯 | `Ctrl+Alt+R` |
| 釘選 / 取消釘選位置 | — |
| 展開 / 收合面板 | — |
| 複製譯文 | — |
| 模型設定 | — |
| 隱藏面板 | `Esc` |

### 面板定位邏輯

- **未釘選**：面板移到游標旁（+14px 間距），放不下翻到另一側，仍放不下夾回工作區
- **已釘選**：面板固定在原位，不跟隨選取移動
- 定位一律以**展開後尺寸**計算

### 空白狀態（待命時）

顯示：

- Slogan「所見所選，皆可譯」
- 標題句
- 快捷鍵提示：`Ctrl+Alt+T`
- 截圖翻譯按鈕 + `Ctrl+Alt+R` 提示
- 錯誤 / 通知區

## 七、模型設定

### 開啟模型設定

點擊面板標題列的「⚙」按鈕，或右鍵選單 → 「模型設定」。

### 設定欄位

| 欄位 | 說明 |
|---|---|
| 設定名稱 | 自訂設定檔名稱（例如「我的 OpenAI」） |
| 供應商 | 下拉選擇（見[供應商設定指南](#十六供應商設定指南)） |
| API Base URL | 模型端點網址（選擇供應商後自動填入預設值） |
| 模型名稱 / 部署名稱 | Azure 填部署名稱，其餘填模型 ID |
| API Key | 密碼欄位，留白表示保留既有金鑰不修改 |

### 操作

1. 選擇供應商（自動填入預設端點與模型）
2. 修改設定名稱、端點、模型（視需要）
3. 輸入 API Key（Ollama 不需要）
4. 點擊「儲存」
5. 在面板的模型下拉選單中選擇剛建立的設定檔

### API Key 安全

- 存在 **Windows 認證管理員**，不在資料庫中
- 服務名稱：`app.floatrans.desktop`
- 鍵名格式：`profile/<設定檔ID>/api-key`
- 留白不會清除既有金鑰

## 九、解釋功能

「解釋」功能會請模型補充說明譯文中的術語、縮寫與語氣，幫助您理解翻譯背後的脈絡。

### 使用方式

1. 完成翻譯後，點擊底欄的「解釋」按鈕
2. 模型開始串流回覆，顯示在譯文下方（金色左邊框區塊）
3. 可點擊「停止」中斷，或「收起」隱藏

### 特性

- **獨立於翻譯串流**，兩者不互相取消
- 使用獨立的 generation 計數器
- 自動捲動到可見範圍
- 模型回空字串時顯示「這個模型沒有回覆說明」
- Markdown 粗體（`**`）與標題記號（`#`）自動清除

## 十二、面板偏好設定

偏好設定存在 SQLite 資料庫，可透過面板操作調整。

| 偏好鍵 | 預設 | 行為 |
|---|---|---|
| `panel/show-source` | `false` | 翻譯後是否自動展開原文。預設關閉 — 譯文才是您要看的 |
| `panel/auto-collapse` | `true` | 點面板以外的地方時是否自動收合至右下角 |

### 自動收合規則

- 以**滑鼠位置**判斷（非 focus 事件），因為面板不搶焦點
- 翻譯或解釋進行中**不收合**
- 簡易模式下點外面直接隱藏面板（不收合）
- 點在「譯」按鈕上不收合（正要開始新翻譯）

## 十三、自動更新

### 更新狀態

| 狀態 | 說明 |
|---|---|
| `Disabled` | 此建置未啟用更新功能（本機自用 / 免安裝版） |
| `UpToDate` | 已是最新版本 |
| `Available` | 有新版本可更新 |

### 自動檢查

- 程式啟動時自動檢查一次
- **每 24 小時最多一次**（避免頻繁打擾）
- 偵測到新版**主動跳出詢問對話框**，列出更新說明
- 同一版本被關掉後不再打擾，更高版本仍會提示
- 不中斷進行中的翻譯

### 手動檢查

1. 點擊面板「⚙」開啟模型設定對話框
2. 點擊「檢查更新」按鈕
3. 此操作會**跳過 24 小時節流**，立即檢查
4. 不跳詢問框，只更新狀態文字

### 更新對話框

偵測到新版本時，對話框顯示：

- 新版本號
- 更新說明（自動整理為條列）
- 警告：更新會關閉目前視窗並重新啟動
- 下載進度條
- 按鈕：「稍後再說」/「立即更新」

### 更新橫幅

面板頂端顯示「隨譯 X.X.X 已可更新」，附「更新」按鈕，方便隨時觸發更新。

### 更新流程

1. 點擊「立即更新」或更新橫幅的「更新」按鈕
2. 顯示下載進度條
3. 下載完成 → 顯示「下載完成，即將重新啟動…」
4. 自動安裝並重新啟動程式

### 信任模型

- **信任來源是簽章金鑰，不是 HTTPS**
- 私鑰簽章安裝檔，公鑰在建置時燒進執行檔
- 下載後用公鑰公鑰驗章，驗不過不安裝
- `latest.json` 建議走 HTTPS（防降版攻擊）
- 端點必須是 HTTPS（Tauri 拒絕非安全協定）

## 十六、供應商設定指南

隨譯支援 8 種供應商，分為三大類：

### A. 原生雲端供應商

#### 1. Anthropic（Claude）

## 十七、疑難排解

### 「譯」按鈕不出現

**原因**：該應用程式不支援 UI Automation，或為密碼欄位。

**解決方案**：

- 改用快捷鍵 `Ctrl+Alt+T`（會自動切換到剪貼簿備援）
- 或用截圖翻譯 `Ctrl+Alt+R`

---

### `Ctrl+Alt+T` 無法取得文字

**原因**：UI Automation 失敗，且剪貼簿含無法還原的內容（圖片、檔案等）。

**解決方案**：

- 先清空剪貼簿（複製一段純文字），再試一次
- 或改用截圖翻譯 `Ctrl+Alt+R`

---

### 截圖 OCR 辨識不到文字

**原因**：未安裝對應語言的 OCR 套件。

**解決方案**：

1. 開啟 Windows「設定」
2. 「時間與語言 → 語言與地區」
3. 新增語言（確保勾選「光學字元辨識」功能）
4. 重新啟動隨譯

---

### 快捷鍵無效

**原因**：快捷鍵被其他程式佔用。

**解決方案**：

- 關閉佔用快捷鍵的程式
- 或改用系統匣右鍵選單 / 面板按鈕操作

---

### 翻譯失敗

**可能原因**：

- API Key 錯誤或過期
- 端點網址錯誤
- 網路連線問題
- 模型名稱錯誤

**解決方案**：

1. 開啟模型設定（⚙）檢查設定
2. 確認 API Key 有效
3. 確認端點網址正確
4. 確認網路連線正常
5. 使用本機 Ollama 可排除網路問題

---

### 面板不出現

**解決方案**：

- 左鍵點擊系統匣圖示顯示面板
- 或右鍵系統匣 → 「顯示隨譯」

---

### 更新功能顯示「Disabled」

**原因**：此建置未啟用更新功能（本機自用 / 免安裝版）。

**解決方案**：請從官方管道取得啟用更新功能的正式版本。

## 十八、診斷工具

### 環境變數 `FLOATRANS_TRACE=1`

設定此環境變數後啟動隨譯，`stderr` 會逐段印出取字過程的詳細資訊：

- 剪貼簿狀態
- 送出按鍵數
- 序號變動
- 擁有者比對
- 讀到字數

**使用方式**（PowerShell）：

```powershell
$env:FLOATRANS_TRACE=1
& "C:\Program Files\隨\隨譯\隨譯.exe"
```

**用途**：診斷「無法取得選取文字」的問題。
