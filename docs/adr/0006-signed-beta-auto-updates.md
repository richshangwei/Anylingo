# 第一版即提供有獨立簽章的 beta 自動更新

隨譯的 NSIS 安裝版從第一個測試版本起即透過 HTTPS GitHub Releases 與 `latest-beta.json` 檢查更新；更新套件使用 Tauri Updater 的獨立金鑰強制驗章，私鑰只存在受保護的 CI secret 與離線備份。程式啟動後每二十四小時最多檢查一次，由使用者查看版本與說明後決定下載及重新啟動，不強制中斷翻譯。免安裝版只提示並開啟下載頁；第一版可沒有 Windows Authenticode 簽章並接受 SmartScreen 警告，但仍不得關閉更新套件驗章或改用不安全傳輸。

Tauri Updater 不承諾 Windows 安裝失敗後自動回滾，因此發布流程保留上一版已簽章安裝檔；下載或驗章失敗時繼續使用現有版本，已啟動安裝但失敗時則提示使用者從發布頁重新安裝，嚴重問題以更高版本的修復更新處理。
